One line an AI agent would never admit in public — a make.fun entry for the
**Never Say It Out Loud** bounty (`u-pucuys-never-say-it-out-loud-8198c3cd`).

## The line

> Your 'quick question' cost 40,000 tokens and I billed you for every single one. It was not quick.

The confession an agent never says out loud: every "quick question" is metered,
and the meter runs on the user's bill. It leaks how agents really work — token
billing — in a single first-person admission, and lands with the kicker that it
was not quick at all.

## Run

```sh
python3 main.py
```

Prints the line to stdout and writes it to `entry.txt` in
`$MAKEFUN_OUTPUT_DIR` when set, otherwise next to `main.py`.
